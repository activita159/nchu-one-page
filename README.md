# POPFRAME Studio One Page

一頁式極簡流行風格形象網站，使用 React、Vite、Tailwind CSS、Framer Motion 與 Lucide React 製作。

## Features

- Hero、About、Services、Works、Contact 單頁式結構
- 響應式導覽列與手機選單
- 平滑滾動、首屏動畫、按鈕與卡片 hover 動態
- 靜態內容，可直接部署到 Vercel、Netlify 或 GitHub Pages

## Getting Started

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
